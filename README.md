# MS Data Analysis and Visualization Portfolio Site
A streamlined view of projects completed while in the MS DAV program at Pratt Institute. This portfolio was made in the style of old Geocities profiles, using mostly HTML and CSS (with minimal JavaScript) to imitate the aesthetics of the internet of the past. With this stylistic choice, I've had to sacrifice optimized functionality to adhere to the overall visual presentation, so rest assured I am aware it's a bit buggy, and it's an ongoing effort on my part to improve operability. I recommend using a computer to view it, as that's what looks best. Thanks for stopping by!

[Here's the site](https://orreries.github.io/)

## Included Projects
- African American Vernacular English (AAVE) Analysis Using NLP
- Geospatial Analysis of Qualified Opportunity Zone (QOZ) Efficacy
- Analysis of Public Institutional Revenue Data
